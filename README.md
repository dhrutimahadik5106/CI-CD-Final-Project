
# CI/CD Final Project

## Project Name
Continuous Integration and Continuous Delivery (CI/CD) Final Project - JavaScript

## Description
This project demonstrates Continuous Integration and Continuous Delivery using GitHub Actions, Tekton, Docker, and OpenShift.

## Objectives
- Create a CI pipeline using GitHub Actions.
- Perform linting and unit testing.
- Create Tekton tasks for linting, testing, and image building.
- Build a container image.
- Deploy the application to OpenShift using a CD pipeline.

## Technologies Used
- JavaScript
- Node.js
- GitHub Actions
- Tekton
- Docker
- OpenShift
